# 🔄 Sistemas Managua - Portal de Control

Centro de control digital unificado para la gestión de inventario, pedidos, contabilidad diaria y medición automatizada de tanques.

## 📱 Componentes del Sistema
* **Plataforma Web:** Interfaz responsiva alojada en GitHub Pages para el registro de datos.
* **App Android:** Contenedor optimizado (WebView) con sistema integrado de actualización automática remota.
* **Base de Datos:** Sincronización en tiempo real con Google Spreadsheets mediante Google Apps Script.

## 🚀 Instalación para Personal
1. Descargar el archivo `app-release.apk` directamente desde este repositorio en el teléfono.
2. Permitir la instalación de fuentes desconocidas si Android lo solicita.
3. La app se actualizará sola en el futuro cada vez que se publique una mejora.
